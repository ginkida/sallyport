    Settings
    Unfreezes background tabs while the bridge drives them; the page believes it is focused (e.g. Telegram sends read receipts).
    Records console errors/warnings + uncaught exceptions on driven tabs, readable via the console_tail tool. Off by default — it widens the debugger's CDP footprint.
    Records XHR/fetch JSON responses on driven tabs, readable via the network_tail tool — the data behind canvas charts (e.g. Metrika) without screenshots. Off by default — it reads response bodies and widens the debugger's CDP footprint.
    Answers alert/confirm/prompt/beforeunload dialogs on driven tabs automatically (alert → OK, everything else → cancel; steerable via the handle_dialog tool) — an open dialog otherwise freezes the page and stalls automation. Off by default — it widens the debugger's CDP footprint and answers dialogs you might have wanted to see.
    Off by default: an agent's tabs are usually the result you wanted to see, and closing half-finished work is what close_tab's gate protects against. Useful for dispatched/one-shot agents, whose tabs pile up. This switch is GLOBAL — it cannot tell a dispatched agent from an interactive one, so with it on your own session's tabs are closed too when it exits. Closing is skipped for a tab whose ownership epoch no longer matches, and it does no allowlist re-check: an agent tab is closed wherever it has since navigated. No effect without a broker (--no-broker), and skipped while paused or while the extension is disconnected.
    A ceiling on how many tabs agents may have open at once (default 20; 0 turns it off). When a new one would cross it, the oldest agent tabs are closed first — tabs left behind by sessions that have already finished, then the creating session's own least-recently-used ones. Never a tab you have looked at (activated in a focused window, or dragged into one of your own), and never another running session's. Without this an agent that visits twenty pages leaves twenty tabs, every finished session adds more, and nothing ever bounds the total.
    Agent tabs (0)
    Tabs the agents opened, grouped by session. They are ordinary tabs in this profile — same logins as yours — and by default they stay open when a session ends, so this is where you sweep up what's left behind.
